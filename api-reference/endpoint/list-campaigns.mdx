---
title: "Listar campanhas"
description: "Campanhas de voz e de WhatsApp da organização, com paginação"
openapi: "GET /api/v1/campaigns"
---

A lista traz os dois canais juntos. Use o campo `channel` de cada item para distinguir campanha de ligações (`voice`) de campanha de mensagens (`whatsapp`).

## Filtros

| Parâmetro | Valores | Padrão |
|-----------|---------|--------|
| `page` | Número da página | `1` |
| `limit` | Itens por página, máximo 100 | `20` |
| `status` | `PENDING`, `IN_PROGRESS`, `COMPLETED`, `FAILED`, `CANCELLED` | Todos |
| `project_id` | ID de um projeto da organização | Todos |

Um `status` fora da lista responde `400` em vez de devolver uma lista vazia — assim um erro de digitação não passa por "nenhuma campanha".

## Campos por canal

Campanhas de WhatsApp vêm com `agent`, `phone_number`, `config` e `started_at` nulos, e com `template_name` preenchido. Os detalhes de cada campo estão em [Detalhes da campanha](/api-reference/endpoint/get-campaign).

<Note>
  A lista **não** traz os destinatários, só os contadores (`total_recipients`, `dispatched_count`, `completed_count`, `failed_count`). Para ver contato a contato, e o motivo de cada falha, use o endpoint de detalhes.
</Note>

  -H "Authorization: Bearer ik_live_xxx"
