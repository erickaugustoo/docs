## Base URL

```
https://api.useintegra.com.br
```

## Autenticação

Todos os endpoints requerem autenticação via API Key no header `Authorization`:

```bash
Authorization: Bearer ik_live_sua_key_aqui
```

<Card title="Como obter uma API Key" icon="key" href="/authentication">
  Gere sua key no painel da Integra em Settings > API Keys.
</Card>

## Endpoints disponíveis

### Campanhas

| Método | Endpoint | Descrição |
|--------|----------|-----------|
| `GET` | `/api/v1/campaigns` | Listar campanhas da organização |
| `GET` | `/api/v1/campaigns/{id}` | Detalhes de uma campanha |
| `POST` | `/api/v1/campaigns` | Criar nova campanha de ligações |

### Chamadas

| Método | Endpoint | Descrição |
|--------|----------|-----------|
| `GET` | `/api/v1/calls` | Listar histórico de chamadas |
| `GET` | `/api/v1/calls/{id}` | Detalhes de uma chamada |

### CRM

| Método | Endpoint | Descrição |
|--------|----------|-----------|
| `GET` | `/api/v1/crm/pipelines` | Listar funis com as etapas |
| `GET` | `/api/v1/crm/contacts` | Listar contatos |
| `POST` | `/api/v1/crm/contacts` | Criar ou atualizar um contato pelo telefone |
| `PATCH` | `/api/v1/crm/contacts/{id}` | Alterar um contato |
| `GET` | `/api/v1/crm/deals` | Listar negócios |
| `POST` | `/api/v1/crm/deals` | Criar um negócio |
| `PATCH` | `/api/v1/crm/deals/{id}` | Mover, alterar ou fechar um negócio |
| `GET` | `/api/v1/crm/activities` | Linha do tempo de um contato ou de um negócio |
| `POST` | `/api/v1/crm/activities` | Registrar uma nota |
| `GET` | `/api/v1/crm/fields` | Listar as colunas personalizadas |
| `POST` | `/api/v1/crm/fields` | Criar ou atualizar uma coluna personalizada |
| `PATCH` | `/api/v1/crm/fields/{id}` | Alterar uma coluna |
| `DELETE` | `/api/v1/crm/fields/{id}` | Arquivar uma coluna |

As rotas do CRM pedem os escopos `crm:read` (consulta) e `crm:write` (criar, alterar e arquivar) na API Key.

## Rate Limiting

Limite de **60 requests por minuto** por API Key. Veja [Rate Limiting](/rate-limiting) para mais detalhes.

## Formato de erro

```json
{
  "error": "Descrição do erro"
}
```

Veja [Erros](/errors) para a lista completa de códigos.
