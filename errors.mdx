Todas as respostas de erro seguem o mesmo formato JSON.

## Formato

```json
{
  "error": "Descrição do erro"
}
```

## Códigos de erro

| Status | Erro | Causa |
|--------|------|-------|
| `400` | Bad Request | Body ou parâmetros inválidos |
| `401` | Unauthorized | API Key ausente, inválida ou revogada |
| `403` | Forbidden | Sem permissão para o recurso |
| `404` | Not Found | Recurso não encontrado |
| `422` | Unprocessable Entity | Regra de negócio impediu a operação (ver abaixo) |
| `429` | Too Many Requests | [Rate limit](/rate-limiting) excedido (60 req/min) |
| `500` | Internal Server Error | Erro interno — contate suporte |
| `502` | Bad Gateway | Falha na comunicação com o serviço de WhatsApp |
| `503` | Service Unavailable | Integração de WhatsApp não configurada na organização |

## Erros de campanha de WhatsApp

O canal `whatsapp` tem regras que só podem ser verificadas no momento da chamada. Elas respondem `422` com a mensagem em português explicando o que fazer.

| Causa | O que fazer |
|-------|-------------|
| Template ainda não aprovado pela Meta | Aguarde a aprovação. O status aparece no painel, em **Templates** |
| Template desabilitado | Reative o template no painel |
| Variáveis não batem com os `{{n}}` do corpo | Envie exatamente uma chave numérica por marcador. Veja [Criar campanha](/api-reference/endpoint/create-campaign) |
| Lista maior que a quota de 24h do número | Reduza a lista ou divida em dias. Consulte [Conversas disponíveis](/api-reference/endpoint/campaigns-quota) |

<Warning>
  Um `502` na **criação** de campanha não garante que a campanha deixou de ser criada. Antes de repetir, [liste suas campanhas](/api-reference/endpoint/list-campaigns) e procure pelo `name` enviado. Repetir às cegas dispara o template duas vezes para a lista inteira.
</Warning>

## Exemplos

### Key inválida (401)

```bash
curl -H "Authorization: Bearer ik_live_invalida" \
  https://api.useintegra.com.br/api/v1/campaigns
```

```json Response
{
  "error": "Invalid or revoked API key"
}
```

### Recurso não encontrado (404)

```bash
curl -H "Authorization: Bearer ik_live_xxx" \
  https://api.useintegra.com.br/api/v1/campaigns/id-inexistente
```

```json Response
{
  "error": "Campaign not found"
}
```

### Rate limit excedido (429)

```json Response
{
  "error": "Rate limit exceeded. Try again later."
}
```

<Tip>
  Sempre verifique o campo `error` na resposta para entender o que aconteceu. Os erros são descritivos em inglês para facilitar o debugging.
</Tip>
